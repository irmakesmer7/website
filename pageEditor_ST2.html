Splash Page

Technical Description

I designed the Splash page as the entry point of the website. I used semantic HTML elements such as header, main, and section to organise the layout. CSS Flexbox was used to centre the content and create a visually balanced design. The page introduces SDG 3 and includes an image and navigation button for entering the website.

Accessibility

Alt text is provided for all images and headings are structured clearly. The layout is simple, making it easy to understand and navigate for all users.

Action Impact Simulator

Technical Description

The AIS page is an interactive feature developed using HTML, CSS, and JavaScript. Users can select different actions related to health and wellbeing, and the total impact score is updated dynamically. CSS Grid was used to structure the card layout, and JavaScript was used to handle user interaction and scoring logic.

Accessibility

The simulator supports keyboard interaction, and all images include alt text. The layout is clear and responsive, making it accessible for different users and devices.

Content Page

Technical Description

The Content page presents structured information about healthy habits using sections, headings, and images. CSS was used to maintain consistent styling, spacing, and readability. Images were included to visually support the content.

Accessibility

Clear heading hierarchy and descriptive alt text improve accessibility. The content is organised into sections to make it easier to read and understand.
